# Relecloud Event Management Platform
## Product Requirements Document (PRD)

## Overview

Relecloud is an event management platform that helps event organisers create, manage and monitor live events, conferences and customer experiences.

The platform should provide a modern web experience for both event organisers and attendees.

---

## Problem Statement

Event organisers currently use multiple disconnected systems to:

- Create events
- Manage venues
- Track registrations
- Communicate with attendees
- Monitor event performance

A unified platform is needed to simplify operations and improve visibility.

---

## Target Users

### Event Organiser

Responsibilities:

- Create and manage events
- Monitor registrations
- Review attendance
- Manage communications

### Event Attendee

Responsibilities:

- Browse events
- Register for events
- View schedules
- Manage personal bookings

### Administrator

Responsibilities:

- User management
- Platform configuration
- Reporting and analytics

---

## Core Features

### Event Dashboard

Users can:

- View upcoming events
- See registration statistics
- Monitor attendance metrics
- Access recent activity

### Event Management

Users can:

- Create new events
- Edit existing events
- Cancel events
- Duplicate events

### Registration Management

Users can:

- View attendee lists
- Approve registrations
- Export registrations
- Search attendees

### Analytics

Users can:

- View event performance
- See attendee trends
- Track registrations over time
- Export reports
